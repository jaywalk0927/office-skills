# 사내 먼저간DAY 신청

실제 브라우저 작업 전 [공통 작업 절차](references/workflow.md)를 읽는다. 이 스킬 폴더 하나로 실행할 수 있다.

## 운영 규칙

2026-10-15 사용자 확인: **월 1회, 금요일만 사용 가능하며 같은 날 다른 연차와 중복 사용할 수 없다.** 다른 연차에는 전일 연차·반차·반반차·0.75일 조합이 포함된다. 이 규칙을 같은 분류에 있는 훈련·재택·포상휴가 등에 확대 적용하지 않는다.

| 화면 항목 | 선택값 |
|---|---|
| 상단 신청항목 | 근태신청 |
| 휴가종류 | 기타휴가/근태 |
| 휴가구분 | 먼저간DAY |
| 신청일수 / 종료일 | 0.5 / 비활성화 |
| 제출 후 조회 | 근태 → 근태신청 |

## 작성

1. 사용 날짜와 사유를 확인하고 달력상 금요일인지 검증한다. 월 횟수는 **사용일이 속한 달**을 기준으로 확인한다. 다음 달 사전 신청 가능 여부는 별도 확인 없이 가능/불가로 단정하지 않는다.
2. 해당 사용월의 기존 먼저간DAY 사용·신청 건과 같은 날짜의 다른 연차를 확인한다. 내역 필터는 신청일 기준이므로 해당 월에 사용한 휴가라도 더 앞선 달에 제출했을 수 있다. 필요하면 신청일 범위를 넓혀 사용일을 대조한다.
3. 월 횟수나 같은 날 중복이 충돌하면 그대로 제출하지 않는다. 다른 금요일 선택 또는 사용자가 요청한 기존 건 취소의 실제 반영을 먼저 해결한다. 승인된 오전 반차와도 함께 쓸 수 없다.
4. 먼저간DAY는 오후 반일 제도다. 일반 오후 반차를 추가로 한 건 더 신청하지 않는다. 화면의 0.5 표시만으로 일반 연차가 0.5일 차감된다고 단정하지 않는다.
5. 공통 절차로 제출·조회한다. 취소 후 사용권이 즉시 복구된다는 보장은 없으므로 실제 반영 상태를 확인한다.

## 호출 예시

`$hct-early-friday-leave 이번 금요일 먼저간DAY 신청 전에 이번 달 사용 여부와 같은 날 연차를 확인해줘.`
