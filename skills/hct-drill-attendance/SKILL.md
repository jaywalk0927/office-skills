# 사내 훈련

훈련 일정을 `훈련` 근태로 반영한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `기타휴가/근태` |
| 휴가구분 | `훈련` |

## 필요한 입력

- 훈련 종류·목적과 훈련일 또는 기간을 정리한다.
- 일부 시간만 사용하는 경우 실제 시작·종료 시간을 확인한다.

## 유형별 확인

- `교육`과 `훈련`을 사용자의 실제 참석 목적에 맞춰 구분한다.
- 훈련 인정 범위·유급 여부·인정 시간·증빙 요건은 사용자 정보나 현행 인사 기준으로 확인한다.
- 같은 상위 분류의 먼저간DAY에 적용되는 월 1회·금요일·연차 중복 금지 규칙을 훈련에 옮기지 않는다.

## 사용 예

`$hct-drill-attendance 11월 5일 훈련 참석 근태를 신청해줘. 훈련 안내에 적힌 시간은 9시부터 18시까지야.`
