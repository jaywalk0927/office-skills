# 사내 일반휴직

육아휴직 이외의 일반휴직 요청을 `휴직` 세부값으로 처리한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `휴직` |
| 일반휴직 휴가구분 | `휴직` |
| 이 스킬에서 선택하지 않는 휴가구분 | `육아휴직` |

## 필요한 입력

- 휴직 시작일·종료일과 신청에 필요한 사유를 정리한다.
- 육아 목적 여부가 불명확할 때만 일반휴직인지 육아휴직인지 구분한다.

## 유형별 확인

- 육아휴직 요청을 일반 `휴직` 세부값으로 넣지 않는다.
- 휴직 자격·유급 여부·최대 기간·증빙·복직 절차는 사용자 정보나 현행 인사 기준으로 확인한다.
- 근태 신청만으로 별도 인사 발령이나 복직 처리가 완료되었다고 말하지 않는다.

## 사용 예

`$hct-leave-of-absence 12월 1일부터 31일까지 일반휴직 신청을 준비해줘. 육아휴직은 아니야.`
