# 사내 육아휴직

육아휴직 요청을 `휴직` 분류의 `육아휴직` 세부값으로 신청한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `휴직` |
| 휴가구분 | `육아휴직` |

## 필요한 입력

- 육아휴직 시작일·종료일과 요청 사유를 정리한다.
- 자격이나 사용 가능 기간 판단에 필요한 경우에만 관련 사용 이력과 현행 기준이 요구하는 사실을 확인한다.

## 유형별 확인

- `모성보호`나 일반 `휴직` 세부값으로 대체하지 않는다.
- 사용 자격·분할 사용·허용 기간·유급 여부·증빙 요건은 사용자 정보나 현행 인사 기준으로 확인한다.
- 근태 신청과 별도 인사 처리·지원금 신청·복직 처리를 구분한다.

## 사용 예

`$hct-parental-leave 내년 1월 1일부터 3월 31일까지 육아휴직 신청을 준비해줘.`
