# 사내 반반차 신청

실제 브라우저 작업 전 [공통 작업 절차](references/workflow.md)를 읽는다. 이 스킬 폴더 하나로 실행할 수 있다.

## 신청 대상

| 화면 항목 | 선택값 |
|---|---|
| 상단 신청항목 / 휴가종류 | 근태신청 / 연차휴가 |
| 오전 | 0.25연차(오전) |
| 오후 | 0.25연차(오후) |
| 제출 후 조회 | 근태 → 근태신청 |

## 작성

1. 사용 날짜, 오전/오후, 사유를 확인한다. 필요한 실제 휴가 시간대와 해당 구분의 근무조별 의미가 맞는지 확인한다.
2. 잔여 연차와 기존 신청을 확인한다. 같은 날짜에 먼저간DAY가 있으면 반반차를 추가 신청하지 않는다.
3. 선택 후 신청일수 **0.25**, 종료일 비활성화를 확인한다. 0.25라는 숫자만으로 모든 근무조의 출퇴근 시각을 확정하지 않는다.
4. 공통 절차대로 제출 후 조회한다. 조합 신청의 구성 건인 경우 해당 건의 신청번호와 상태를 구분한다.

## 호출 예시

`$hct-quarter-day-leave 이번 금요일 오후 반반차 신청을 준비해줘.`
