# 사내 모성보호

모성보호 요청을 화면의 해당 사유와 사용 일정에 맞춰 신청한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `모성보호` |
| 휴가구분 | `산휴`, `출산`, `난임`, `태아검진` |

## 필요한 입력

- 요청 사유와 사용일 또는 기간, 시간 단위 요청이면 사용 시간을 정리한다.
- 산휴와 출산 중 적용 항목이 불명확하면 사용자 정보나 현행 인사 기준으로 구분한다.

## 유형별 확인

- `산휴`와 `출산`의 이름만으로 적용 대상이나 일수를 단정하지 않는다. 난임·태아검진을 다른 모성보호 유형으로 대체하지 않는다.
- 자격·유급 여부·허용 기간·증빙 요건은 확인된 기준만 적용한다.
- 신청에 필요한 사실과 증빙 범위만 확인한다. 진단명이나 상세 의료기록을 기본 질문으로 요구하지 않는다.
- 육아휴직 요청을 이 분류로 접수하지 않는다.

## 사용 예

`$hct-maternity-leave 다음 주 수요일 태아검진 근태 신청을 준비해줘. 오전에 사용할 예정이야.`
