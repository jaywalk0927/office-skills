# 사내 포상휴가

부여된 포상휴가와 사용 일정을 맞춰 `포상휴가`로 신청한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `기타휴가/근태` |
| 휴가구분 | `포상휴가` |

## 필요한 입력

- 사용일 또는 기간과 포상휴가 부여 근거를 정리한다.
- 신청에 필요한 잔여 일수·사용 기한이 불명확하면 부여 안내나 현행 기준에서 확인한다.

## 유형별 확인

- 수상·포상 사실만으로 휴가가 자동 부여되었다고 가정하지 않는다. 실제 부여 내용과 사용 가능분을 확인한다.
- 포상휴가의 일수·기한·유급 여부를 연차나 다른 포상 사례에서 가져오지 않는다.
- 같은 상위 분류의 먼저간DAY에 적용되는 월 1회·금요일·연차 중복 금지 규칙을 포상휴가에 옮기지 않는다.

## 사용 예

`$hct-reward-leave 부여받은 포상휴가 1일을 다음 주 월요일에 신청해줘. 사용 기한도 확인해줘.`
