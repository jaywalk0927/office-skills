# 사내 출장

출장 지역과 전일·반일 일정에 맞는 출장 근태를 신청한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `출장` |
| 국내출장 휴가구분 | `국출` |
| 오전 국내출장 휴가구분 | `국출(오전)` |
| 오후 국내출장 휴가구분 | `국출(오후)` |
| 해외출장 휴가구분 | `해출` |
| 국내출장 반일 UI | `0.5`일, 종료일(`endDate`) 비활성화 |

## 필요한 입력

- 국내·해외 구분, 출장 목적·장소, 사용일 또는 시작일·종료일을 정리한다.
- 국내 단일일 일정에서 전일·오전·오후가 불명확한 경우에만 구분을 묻는다.

## 유형별 확인

- `국출(오전)`·`국출(오후)`를 선택하면 0.5일과 종료일 비활성화를 확인한다. 종료일을 강제로 수정하지 않는다.
- 여러 날짜나 전일·반일이 섞이면 실제 일정과 화면 지원 범위에 맞춰 신청 구성을 확인한다.
- 해외출장의 반일 선택값은 확인되지 않았다. 국내출장 반일 동작을 `해출`에 적용하지 않는다.
- 출장 인정 요건·비용 지급·기간 제한은 이 매핑만으로 알 수 없다. 출장 근태와 비용 정산을 구분한다.

## 사용 예

`$hct-business-trip 다음 주 목요일 오후 국내출장 근태를 신청해줘. 목적은 고객사 시험 일정 협의야.`
