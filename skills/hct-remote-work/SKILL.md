# 사내 재택근무

재택근무 일정을 `재택` 근태로 신청한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `기타휴가/근태` |
| 휴가구분 | `재택` |

## 필요한 입력

- 재택근무일 또는 기간과 신청에 필요한 업무·사유를 정리한다.
- 부분일 재택 요청이면 사용 시간과 해당 방식의 허용 여부를 확인한다.

## 유형별 확인

- 재택근무를 휴가 사용이나 연차 차감으로 해석하지 않는다.
- 재택 대상·사전 승인·허용 일수·부분일 지원 여부는 사용자 정보나 현행 인사 기준으로 확인한다.
- 같은 상위 분류의 먼저간DAY에 적용되는 월 1회·금요일·연차 중복 금지 규칙을 재택에 옮기지 않는다.

## 사용 예

`$hct-remote-work 다음 주 수요일 재택근무를 신청해줘. 업무는 시험 결과 보고서 작성이야.`
