# 사내 연중휴가

연중휴가 목적의 근태를 `연중` 항목으로 신청한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `연중휴가` |
| 휴가구분 | `연중` |

## 필요한 입력

- 사용일 또는 시작일·종료일, 신청 사유를 정리한다.
- 연차와 연중휴가 중 어느 제도를 뜻하는지 불명확한 경우에만 구분을 묻는다.

## 유형별 확인

- 연중휴가를 일반 연차나 보상휴가로 바꾸지 않는다.
- 사용 자격·부여 일수·사용 기한·유급 여부는 이 UI 매핑으로 알 수 없다. 신청에 영향을 주는 사항은 사용자 정보나 현행 인사 기준으로 확인한다.
- 선택 후 화면에 계산된 기간·일수를 실제 사용 일정과 대조한다.

## 사용 예

`$hct-year-round-leave 11월 2일부터 3일까지 연중휴가 신청을 준비해줘.`
