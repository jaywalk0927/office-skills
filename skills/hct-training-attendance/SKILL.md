# 사내 교육

교육 참석 일정을 교육 근태로 반영한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `교육` |
| 휴가구분 | `교육` |

## 필요한 입력

- 교육명·목적과 교육일 또는 기간을 정리한다.
- 시간을 구분해 신청해야 하는 경우 교육의 시작·종료 시간을 확인한다.

## 유형별 확인

- 업무 교육 요청과 `훈련` 요청을 구분한다. 교육이라는 단어만으로 모든 외부 행사를 같은 항목에 넣지 않는다.
- 교육 인정 범위·사전 승인·근태 인정 시간은 사용자 정보나 현행 인사 기준으로 확인한다.
- 교육비 지급·출장비 정산·별도 교육 신청까지 처리된 것으로 표현하지 않는다.

## 사용 예

`$hct-training-attendance 11월 4일 외부 직무교육 참석을 교육 근태로 신청해줘.`
