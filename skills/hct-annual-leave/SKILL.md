# 사내 연차 신청

실제 브라우저 작업 전 [공통 작업 절차](references/workflow.md)를 읽는다. 이 스킬 폴더 하나로 실행할 수 있다.

## 신청 대상

| 화면 항목 | 선택값 |
|---|---|
| 상단 신청항목 | 근태신청 |
| 휴가종류 | 연차휴가 |
| 휴가구분 | 연차 |
| 제출 후 조회 | 근태 → 근태신청 |

## 작성

1. 사용 시작일·종료일과 신청사유를 확인한다. 하루이면 같은 날짜를 지정한다.
2. 양식 상단 휴가현황에서 사용 가능 잔여일수를 확인한다. 기존 신청과 날짜 중복 여부도 조회한다.
3. 계산된 신청일수를 의도한 사용일수와 대조한다. 초기 하루 양식의 1은 관찰값일 뿐 여러 날의 일수를 대신하지 않는다. 주말·공휴일이 포함되면 달력 날짜 차이를 연차일수로 단정하지 않는다.
4. 같은 날짜에 먼저간DAY가 있으면 연차와 함께 신청하지 않는다. 기존 건을 임의 취소하지 말고 날짜 변경 또는 사용자가 요청한 취소의 반영 여부를 먼저 해결한다.
5. 공통 절차에 따라 제출·조회하고 접수와 승인을 구분해 보고한다.

## 호출 예시

`$hct-annual-leave 다음 주 월요일 하루 연차 신청을 준비해줘. 사유는 개인 사정이야.`
