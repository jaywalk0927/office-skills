# 사내 근태 신청내역 조회

실제 브라우저 작업 전 [공통 작업 절차](references/workflow.md)를 읽는다. 이 스킬 폴더 하나로 실행할 수 있다.

## 조회 전 확인

사용자, 찾는 신청종류, 제출한 시기, 실제 휴가/근무 날짜 중 필요한 값만 확인한다. 사용일만 알고 있으면 그것을 신청일 필터에 그대로 넣지 않는다. 이 스킬은 조회만 수행하며 신청·취소를 만들지 않는다.

| 조회 탭 | 신청구분 |
|---|---|
| 근태 | 근태신청, 근태신청취소 |
| 근무 | 시차출퇴근 근무 신청, 시프트 근무 신청, 야간 근태신청, 잔업신청, 휴일근무신청 |

## 조회 절차

1. 해당 탭·신청구분을 고른다. **신청일은 제출일**이다. 예를 들어 지난달 제출한 다음달 연차는 지난달이 포함되는 신청일 범위로 조회한다.
2. 상태를 모르면 결재상태를 빈 값(미지정)으로 두고 **상단 조회 버튼 또는 F2**를 실행한다.
3. 신청번호, 휴가구분/신청구분, 시작·종료일, 일수/시간, 결재상태를 대조한다. 비슷한 건이 여러 개면 실제 대상부터 식별한다.
4. 없으면 신청일 범위를 단계적으로 넓히고 탭·종류·상태를 다시 확인한 뒤 매번 조회/F2를 실행한다. 해당 범위에서 안 보인다는 사실과 신청 자체가 없다는 판단을 구분한다.
5. 초안·접수·승인을 구분해서 보고한다. 요청받은 경우 취소 건과 원 신청 상태, 잔여일수/사용권 반영도 별도로 대조한다. 조회에 없는 번호나 상태는 만들지 않는다.

## 호출 예시

`$hct-attendance-status 지난달에 신청한 다음 달 연차가 안 보여. 신청일 범위를 맞춰서 찾아줘.`
