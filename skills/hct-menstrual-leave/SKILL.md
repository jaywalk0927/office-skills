# 사내 생휴

사용자가 요청한 생휴를 `생휴` 근태로 신청한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `기타휴가/근태` |
| 휴가구분 | `생휴` |

## 필요한 입력

- 사용일 또는 기간을 정리한다.
- 신청 자격이나 허용 기간 확인이 필요하면 현행 기준에서 필요한 사실만 확인한다.

## 유형별 확인

- 생휴의 대상·유급 여부·일수·사용 단위·증빙 요건은 사용자 정보나 현행 인사 기준으로 확인한다.
- 신청에 필요하지 않은 증상·진단·의료기록을 기본 질문으로 요구하지 않는다.
- 같은 상위 분류의 먼저간DAY에 적용되는 월 1회·금요일·연차 중복 금지 규칙을 생휴에 옮기지 않는다.

## 사용 예

`$hct-menstrual-leave 다음 주 월요일 생휴 신청을 준비해줘.`
