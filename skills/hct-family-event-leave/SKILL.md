# 사내 경조휴가

경조 사유와 대상 관계에 맞는 `경조`, `결혼`, `탈상`을 선택한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `경조휴가` |
| 휴가구분 | `경조`, `결혼`, `탈상` |

## 필요한 입력

- 사용일 또는 기간, 경조 사유와 본인·가족 등 대상 관계를 확인한다.
- 적용 일수 판정에 필요할 때만 행사 발생일을 확인한다.

## 유형별 확인

- 결혼이라는 사유만으로 휴가구분 `결혼`을 확정하지 않는다. 대상 관계에 맞는 휴가구분과 허용 일수를 사용자 정보나 현행 인사 기준에서 확인한 뒤 선택한다.
- 유급 여부·증빙 요건도 확인된 기준을 적용한다. 다른 경조 사유를 임의로 결혼·탈상에 포함하지 않는다.
- 필요한 증빙이 있으면 요구된 범위만 확인하며, 경조 사유를 세부적으로 추측해 기록하지 않는다.

## 사용 예

`$hct-family-event-leave 본인 결혼에 따른 경조휴가 신청을 준비해줘. 사용 기간은 11월 2일부터 6일까지야.`
