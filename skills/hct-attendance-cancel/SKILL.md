# 사내 근태 신청 취소

실제 브라우저 작업 전 [공통 작업 절차](references/workflow.md)를 읽는다. 이 스킬 폴더 하나로 실행할 수 있다.

## 취소 양식

상단 **근태신청취소** 행의 신청으로 양식을 연다. 휴가종류·휴가구분과 **휴가시작일** 범위로 대상을 찾는다. 이 검색 날짜는 메인 화면의 **신청일(제출일)** 필터와 다르다.

확인된 빈 양식은 신청자, 신청구분 `승인취소`, 신청기간, 변경사유를 제공한다. 대상 선택 전 신청기간과 일수는 비활성화돼 있다. 신청구분의 확인된 선택지는 승인취소 하나이며, 다른 상태의 취소 가능 여부는 현재 화면으로 확인한다.

## 처리

1. 대상의 원 신청번호(있으면), 종류, 사용 날짜·일수, 취소 사유를 확인한다. 먼저 조회하여 원 건의 실제 상태를 대조한다.
2. 취소 양식의 검색 조건에 맞는 원 신청을 선택한다. 여러 건이면 요청한 건인지 식별한 뒤 진행한다. 대상이 보이지 않으면 검색 범위·종류·상태를 점검하며 임의의 다른 건을 선택하지 않는다.
3. 반영된 신청자·종류·신청기간·일수와 원 신청을 대조하고 변경사유를 실제 사유로 작성한다. 비활성 신청기간을 우회 수정하지 않는다.
4. 실제 취소 요청을 받은 범위에서 하단 신청으로 취소를 요청한다. 메인 화면 **근태 → 근태신청취소**에서 제출일 범위를 정하고 **조회/F2**로 취소 요청 접수를 확인한다.
5. 원 신청의 취소 반영과 취소 요청의 결재상태를 별도로 확인한다. **취소 접수, 취소 승인·반영, 잔여 연차·먼저간DAY 사용권 복구는 서로 다른 확인 항목**이다. 즉시 복구를 보장하지 않는다.
6. 시차출퇴근·시프트·야간·잔업·휴일근무의 취소는 이 양식에서 검증하지 않았다. 해당 작업 요청이면 현재 화면에 제공되는 절차를 먼저 확인한다. 상단 삭제 버튼을 취소 요청의 대체 수단으로 사용하지 않는다.

## 호출 예시

`$hct-attendance-cancel 다음 주 금요일 승인된 연차를 취소하고 싶어. 사유는 일정 변경이야. 원 신청부터 확인해줘.`
