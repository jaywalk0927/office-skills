# 사내 휴일근무

휴일의 실제 근무기록으로 신청을 작성하고, 접수·승인과 보상휴가 발생을 구분해 확인한다. 화면 정보는 2026-10-15에 확인했다.

실제 브라우저 작업 전 [작업 절차](references/workflow.md)를 반드시 읽고 따른다.

## 화면과 입력

- 상단 **휴일근무신청**을 열면 양식 제목도 **휴일근무신청**이다.
- 근무기록과 타각, 근무일, 시작·종료 시각, 휴게시간, **신청시간**, **인정시간**, **사유**를 확인한다.
- 목록 안내의 휴일근무 한도는 **1일 최대 8시간**이다. 실제 타각 기록과 신청·인정시간을 대조한다.
- 사용자가 말한 근무시간만으로 인정시간을 확정하거나 없는 타각을 만들지 않는다.

## 승인과 보상휴가

- 양식에는 **휴일근무 승인 후 보상휴가 발생·사용** 흐름이 안내되어 있다.
- 상단 **휴일근무신청**을 누른 것은 양식을 연 단계다. 실제 접수나 승인을 뜻하지 않는다.
- 실제 제출 후 **근무** 탭의 **신청구분: 휴일근무신청**에서 근무일·신청시간·인정시간과 결재상태를 대조한다.
- 근무시간에서 보상휴가로 환산하는 비율은 확인하지 않았다. **8시간 근무 = 보상휴가 1일**로 계산하지 않는다.
- 승인을 확인한 뒤에도 실제 보상휴가 발생량·사용 가능 잔액을 확인한다. 신청 접수 직후 발생했다고 보고하지 않는다.
- 사용까지 요청받았다면 희망 사용일과 사용할 잔액을 확인하고 별도 휴가 신청 절차로 다룬다. 휴일근무 신청과 휴가 사용을 한 동작으로 취급하지 않는다.

## 사용 예

사용자: “$hct-holiday-work 지난 휴일에 8시간 일했어. 휴일근무신청 눌렀으니 보상휴가 1일 바로 써 줘.”

정확한 근무일과 타각·인정시간, 실제 접수·승인 상태를 확인한다. 8시간을 1일로 환산하지 않으며, 보상휴가 발생량과 잔액·사용일이 확인되어야 사용 신청을 준비할 수 있음을 안내한다.
