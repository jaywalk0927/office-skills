# 사내 반차 신청

실제 브라우저 작업 전 [공통 작업 절차](references/workflow.md)를 읽는다. 이 스킬 폴더 하나로 실행할 수 있다.

## 신청 대상

| 화면 항목 | 선택값 |
|---|---|
| 상단 신청항목 / 휴가종류 | 근태신청 / 연차휴가 |
| 오전 | 0.5연차(오전) |
| 오후 | 0.5연차(오후) |
| 제출 후 조회 | 근태 → 근태신청 |

## 작성

1. 사용 날짜, 오전/오후, 사유를 확인한다. 시간대가 빠졌으면 그것만 묻는다.
2. 잔여 연차와 기존 신청을 확인한다. 같은 날짜의 먼저간DAY와는 중복 사용할 수 없다.
3. 해당 구분을 선택하고 신청일수 **0.5**, 종료일 비활성화를 확인한다. 잠긴 종료일은 수정하지 않는다.
4. 오전·오후의 실제 출퇴근 시각은 적용 근무조와 회사 기준으로 확인한다. 명칭만으로 고정 시각을 만들지 않는다.
5. 공통 절차대로 제출 후 조회한다. 0.75일 조합을 위해 별도 요청된 구성 건이라면 이 반차의 접수 상태를 별도로 기록한다.

## 호출 예시

`$hct-half-day-leave 내일 오후 반차를 신청해줘. 사유는 개인 사정이야.`
