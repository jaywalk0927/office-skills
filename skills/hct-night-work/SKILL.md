# 사내 야간근무

독립된 야간근무 신청의 근무시간과 계획서 준비 상태를 확인한다. 화면 정보는 2026-10-15에 확인했다.

실제 브라우저 작업 전 [작업 절차](references/workflow.md)를 반드시 읽고 따른다.

## 화면과 입력

- 상단 **야간 근태신청**을 열면 양식 제목은 **야간근무신청**이다. 시프트근무신청과 별도 업무다.
- 시작일·시각, 종료일·시각, 실제 근무·휴게 계획, 신청 사유와 계획서 준비 상태를 확인한다. “아침까지”만으로 종료 시각을 정하지 않는다.
- 양식에는 **22:00~06:00 시간대 최소 4시간** 및 **야간교대근무 실시 계획서 전자결재 작성 필수**가 안내되어 있다.
- `근무시간`은 자유 입력이 아닌 **검색 선택**이다. 확인된 선택값은 다음과 같다.

| 근무시간 선택값 |
|---|
| 야간(17:00~02:00) |
| 야간(18:00~03:00) |
| 야간(19:00~04:00) |
| 야간(20:00~05:00) |
| 야간(21:00~06:00) |
| 야간(22:00~07:00) |
| 야간(23:00~08:00) |
| 야간(24:00~09:00) |

## 적용 전 확인

- 위 목록의 존재를 확인했으며, 각 선택값의 신청 자격과 익일 처리 방식은 검증하지 않았다. 선택 가능하다는 사실만으로 신청 요건 충족을 판단하지 않는다.
- **24:00** 시작 선택값은 시작 시각에 **00:00**으로 표시된다. 실제 시작일·종료일과 자정의 날짜 귀속을 확인한다.
- “22:00~06:00 시간대 최소 4시간”의 상세 산정 방식은 미확인이다. 모든 근무시간이 그 구간 안에 있어야 한다거나 법적 기준과 같다고 추정하지 않는다.
- 사용자가 야간 규정을 모르면 실제 요청에 적용되는 사내 기준을 인사 담당자 또는 공식 정책으로 확인한다. 근무시간·신청 자격·날짜 처리의 미확인 사항을 남긴 채 임의 신청하지 않는다.
- **야간교대근무 실시 계획서**의 내용과 전자결재 준비·진행 상태를 확인한다. 계획서 작성 필수 안내를 신청 양식 작성만으로 충족했다고 보지 않는다.
- 처리 후 **근무** 탭에서 **신청구분: 야간 근태신청**과 근무일을 대조해 내역·상태를 확인한다.

## 사용 예

사용자: “$hct-night-work 야간근무를 22시부터 아침까지 신청해 줘. 계획서는 몰라.”

정확한 시작일과 종료일·시각을 확인한다. 목록에 **야간(22:00~07:00)**이 있어도 07:00 종료를 대신 결정하지 않는다. 적용 사내 기준과 계획서 내용을 확인하고 전자결재 준비 상태를 파악한 뒤 신청 내용을 확정한다.
