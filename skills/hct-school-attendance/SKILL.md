# 사내 학사

학사 목적의 일정을 `학사` 근태로 신청한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `기타휴가/근태` |
| 휴가구분 | `학사` |

## 필요한 입력

- 학사 일정의 목적과 사용일 또는 기간을 정리한다.
- 시간 단위 요청이면 해당 일정의 시작·종료 시간을 확인한다.

## 유형별 확인

- 학교 관련 일정이라는 이유만으로 모두 인정된다고 단정하지 않는다. 적용 대상·허용 시간·유급 여부·증빙은 사용자 정보나 현행 인사 기준으로 확인한다.
- 업무 교육 요청을 임의로 `학사`에 넣지 않는다.
- 같은 상위 분류의 먼저간DAY에 적용되는 월 1회·금요일·연차 중복 금지 규칙을 학사에 옮기지 않는다.

## 사용 예

`$hct-school-attendance 다음 주 화요일 학사 일정에 대한 근태 신청을 준비해줘. 일정은 오후 2시부터 5시까지야.`
