# 사내 대체휴가

휴일근무 예정 여부와 사용 목적에 맞는 대체휴가 세부값을 선택한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `대체휴가` |
| 이번 주 휴일근무 예정자 휴가구분 | `대휴(이번주휴일근무예정자)` |
| 그 밖의 대체휴가 휴가구분 | `대휴` |

## 필요한 입력

- 대체휴가 사용일 또는 기간과 관련 휴일근무 일정을 확인한다.
- 휴일근무가 이번 주 예정인지, 이미 수행한 근무에 대한 요청인지 구분한다.

## 유형별 확인

- 사용자의 상황이 이번 주 휴일근무 예정자에 해당할 때 해당 세부값을 선택한다. 단순히 앞으로 근무할 예정이라는 이유로 범위를 넓히지 않는다.
- 예정자용 선택값의 존재만으로 사전 사용 자격이나 승인이 보장되는 것은 아니다. 필요한 근무 승인·발생 근거와 현행 기준을 확인한다.
- 대휴 발생량·환산·사용 기한·유급 여부는 추정하지 않는다. 보상휴가와 서로 바꾸어 처리하지 않는다.

## 사용 예

`$hct-substitute-leave 이번 주 일요일 근무 예정에 대한 대체휴가를 신청하고 싶어. 다음 주 수요일에 사용할 거야.`
