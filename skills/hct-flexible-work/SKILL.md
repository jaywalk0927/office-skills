# 사내 시차출퇴근

1주 이상 출퇴근 시간을 조정하는 시차출퇴근 신청을 작성·확인한다. 화면 정보는 2026-10-15에 확인했다.

실제 브라우저 작업 전 [작업 절차](references/workflow.md)를 반드시 읽고 따른다.

## 화면과 입력

- 상단 신청 목록의 **시차출퇴근 근무 신청**을 열면 양식 제목은 **시차출퇴근**이다.
- 신청기간, 근무조, 주요업무, 신청사유를 준비한다. 기간은 시작일과 종료일로 확인한다.
- 신청기간은 **1주 이상**이다. 지정 A·C·D조 외의 시간은 **전자결재가 필요**하다.

근무조 검색에서 확인된 선택값:

| 근무시간 | 근무조 |
|---|---|
| 07:00~16:30 | A조 |
| 07:00~16:00 | A조(조식x) |
| 10:00~19:30 | C조 |
| 10:00~19:00 | C조(석식x) |
| 12:30~21:30 | D조 |

## 선택 및 완료 확인

- 사용자 희망 시간과 식사 조건에 맞는 검색 결과를 선택한다. 같은 조의 식사 제외 선택값을 혼동하지 않는다.
- 검색 결과의 **적용**은 근무조 필드를 채우는 동작이다. 적용만으로 신청 접수나 결재 완료를 보고하지 않는다.
- 전자결재가 필요한 시간이라면 해당 결재의 준비·진행 상태를 확인한다. 지정조를 임의로 대신 선택하지 않는다.
- 처리 후 **근무** 탭에서 **신청구분: 시차출퇴근 근무 신청**과 기간을 대조해 신청 내역·상태를 확인한다.

## 사용 예

사용자: “$hct-flexible-work 다음 주부터 2주간 10시 출근, 석식 없이 시차출퇴근 신청해 줘.”

시작일·종료일과 주요업무·신청사유를 확인하고 **10:00~19:00 C조(석식x)**를 선택한다. 적용된 값과 기간을 검토하고, 작업 절차에 따라 신청 결과를 확인한다.
