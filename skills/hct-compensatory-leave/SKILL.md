# 사내 보상휴가

발생·승인이 확인된 보상휴가를 사용할 시간에 맞춰 신청하거나 사용내역을 조회한다.

실제 브라우저 조작 전 [공통 작업 절차](references/workflow.md)를 읽는다.

## ERP 선택값

2026-10-15 실화면에서 확인한 값이다.

| 화면 항목 | 선택값 또는 동작 |
|---|---|
| 양식 열기 | 상단 `근태신청` 행의 `신청` |
| 제출 후 조회 | `근태` 탭 / 신청구분 `근태신청` |
| 휴가종류 | `보상휴가(오전)` 또는 `보상휴가(오후)` |
| 8시간 휴가구분 | `(8시간)보상휴가` |
| 7시간 휴가구분 | `(7시간)보상휴가(오전)`, `(7시간)보상휴가(오후)` |
| 6시간 휴가구분 | `(6시간)보상휴가(오전)`, `(6시간)보상휴가(오후)` |
| 5시간 휴가구분 | `(5시간)보상휴가(오전)`, `(5시간)보상휴가(오후)` |
| 4시간 휴가구분 | `(4시간)보상휴가(오전)`, `(4시간)보상휴가(오후)` |
| 3시간 휴가구분 | `(3시간)보상휴가(오전)`, `(3시간)보상휴가(오후)` |
| 2시간 휴가구분 | `(2시간)보상휴가(오전)`, `(2시간)보상휴가(오후)` |
| 1시간 휴가구분 | `(1시간)보상휴가(오전)`, `(1시간)보상휴가(오후)` |
| 관련 조회 항목 | `보상휴가조회`, `보상휴가 사용일수` |
| 8시간 선택 시 UI | 양쪽 휴가종류에서 기본 휴가구분은 `(8시간)보상휴가`, 신청일수 `1`, 종료일 활성화 |

## 필요한 입력

- 신청인지 사용내역 조회인지, 사용일 또는 조회 기간을 정리한다.
- 신청에는 사용할 시간 수와 오전·오후를 현재 요청·기존 답변에서 먼저 확인하고 **빠진 값만 질문한다.** `오후 3시간`이 주어졌다면 휴가종류 `보상휴가(오후)`·휴가구분 `(3시간)보상휴가(오후)`를 사용하며 오전/오후를 다시 묻지 않는다.
- 발생 근거, 승인 상태, 사용 가능한 잔여분이 확인되지 않으면 관련 조회부터 한다.

## 유형별 확인

- 보상휴가의 발생·승인과 잔여분을 확인한 뒤 사용한다. 근무했다는 사실만으로 보상휴가가 발생했다고 단정하지 않는다.
- 8시간 선택 시 신청일수 1이 표시되어도 `8시간 = 1일`을 보편적인 차감 환산 규칙으로 쓰지 않는다. 실제 `보상휴가 사용일수`와 적용 기준을 확인한다.
- 시간대별 선택값을 실제 사용 구간과 맞춘다. 사용 가능 기한·유급 여부·부여 한도는 확인된 사용자 정보나 현행 인사 기준이 있을 때만 적용한다.

## 사용 예

`$hct-compensatory-leave 다음 주 금요일 오후 3시간 보상휴가를 신청해줘. 발생 승인과 잔여분을 먼저 확인해줘.`
