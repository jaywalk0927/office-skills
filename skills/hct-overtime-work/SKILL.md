# 사내 잔업

실제 근무기록을 바탕으로 잔업 신청 가능 조건과 시간을 확인한다. 화면 정보는 2026-10-15에 확인했다.

실제 브라우저 작업 전 [작업 절차](references/workflow.md)를 반드시 읽고 따른다.

## 화면과 입력

- 상단 **잔업신청**을 열면 양식 제목도 **잔업신청**이다.
- **근무기록조회**로 근무일의 타각과 근무기록을 확인한다.
- 근무일, 시작·종료 시각, 휴게시간, **신청시간**, **인정시간**, **사유**를 대조한다. 신청시간과 인정시간이 같다고 가정하지 않는다.

## 신청 조건

| 항목 | 확인된 안내 |
|---|---|
| 선행 근무시간 | 휴게시간을 제외한 근무 8시간 이상 |
| 잔업 한도 | 1일 최대 6시간 |
| 타각 | 타각이 없으면 신청 불가 |
| 부족 시간 | 선행 근무가 1분 부족해도 신청 불가 |
| 일반 신청기한 | 근무일 기준 3일 이내 |
| 매월 16~18일 | 1일 이내 신청 |

- 타각 누락이나 8시간 미달을 입력값 변경으로 우회하지 않는다. 누락된 기록의 정정이 필요하면 실제 근무 증빙에 따른 사내 정정 절차를 확인한다.
- 없는 출퇴근 기록·휴게시간을 만들거나 부족한 분을 반올림하지 않는다.
- 신청기한의 달력일·영업일 계산 방식은 미확인이다. 경계일의 가능 여부를 임의로 확정하지 말고 적용 기준 또는 현재 화면 검증 결과를 확인한다.
- 근무일·시간과 기록이 맞고 신청 조건을 충족할 때 신청 내용을 확정한다. 처리 후 **근무** 탭에서 **신청구분: 잔업신청**과 근무일을 대조해 내역·상태를 확인한다.

## 사용 예

사용자: “$hct-overtime-work 휴게시간 빼고 7시간 59분 일했는데 잔업 2시간 신청해 줘.”

근무기록조회 결과가 실제로 7시간 59분이면 8시간 요건에 1분 부족하므로 신청할 수 없음을 안내한다. 8시간으로 올려 입력하지 않으며, 기록 자체가 잘못되었다는 근거가 있을 때 정정 절차를 확인한다.
