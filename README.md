# 사내 업무 도우미

**임직원의 사내 업무 전용 플러그인입니다.**

구매요청 1개, 근태 26개, 의료비 지원 1개를 함께 제공하는 플러그인입니다. 필요한 업무 스킬 하나를 선택해서 사용하며, 오전·오후 같은 세부 선택지는 해당 스킬 안에서 처리합니다.

플러그인 버전: **1.1.4** · 의료비 안내·양식 확인: **2026-10-23** · 스킬 갱신: **2026-10-27**

## 팀원 설치

저장소: [jaywalk0927/hct-office](https://github.com/jaywalk0927/hct-office)

GitHub CLI를 사용할 때는 GitHub 계정으로 로그인한 뒤 받습니다. ERP 또는 그룹웨어 로그인은 별도로 필요합니다.

```powershell
gh auth login
gh repo clone jaywalk0927/hct-office
cd hct-office
codex plugin marketplace add .
codex plugin add hct-office@hct-team
```

이미 GitHub 인증이 되어 있으면 로그인 단계를 생략합니다. Git만 사용하는 경우에는 `git clone https://github.com/jaywalk0927/hct-office.git`으로 받은 뒤 나머지 명령을 실행합니다.

CLI 대신 Codex의 플러그인 화면에서 등록된 **사내 팀 업무 플러그인** 마켓플레이스를 선택하고 **사내 업무 도우미**를 설치해도 됩니다. 설치 후 새 채팅에서 사용하며, 목록이 갱신되지 않으면 앱을 다시 시작합니다.

소스 폴더를 따로 관리하지 않으려면 다음과 같이 저장소를 마켓플레이스로 직접 등록할 수도 있습니다. 두 방법 중 하나를 사용합니다.

```powershell
codex plugin marketplace add jaywalk0927/hct-office --ref main
codex plugin add hct-office@hct-team
```

## 팀원 업데이트

직접 clone한 폴더를 등록한 경우 해당 폴더에서 실행합니다. `--ff-only`는 로컬 수정과 충돌하는 변경을 자동으로 합치지 않습니다.

```powershell
git pull --ff-only
codex plugin add hct-office@hct-team
```

GitHub 저장소를 마켓플레이스로 직접 등록한 경우에는 다음을 실행합니다.

```powershell
codex plugin marketplace upgrade hct-team
codex plugin add hct-office@hct-team
```

그다음 새 채팅을 시작합니다. 저장소 수정 권한은 저장소 소유자가 관리합니다.

| 의료비 지원 | 병원·약국 PDF·이미지 영수증 읽기, 본인·가족 기준 확인, 상급 결재자 질문, 그룹웨어 신청서 작성·첨부·상신 확인 |

구매요청은 **v1.1.9**, 근태는 **v1.0.1 26종**으로, 보상휴가의 기존 시간대 답변 재사용과 신청 건별 본문 대조를 보강했으며 Aside 우선 브라우저 규칙을 유지했습니다. 구매 안내문 **v1.2(2026-09-30)** PDF와 참조 자료도 포함합니다. 의료비 지원 **v1.0.2**는 그룹웨어 복리후생 게시물과 실제 신청서 양식을 기준으로 하며, 기본 제목 유지·본인/가족 체크·셀 입력과 정상값 복구·원본과 시험 입력값 구분·작은 대표자명 확인·미상신 첨부 상태 보고를 반영했습니다. 별도 스킬 설치 안내인 구매요청 README는 이 플러그인 안내로 대신합니다.

## 사용 예

플러그인을 설치·선택한 채팅에서 자연어로 요청합니다. 각 업무 스킬도 개별 선택할 수 있습니다.

- “이 견적서로 사내 구매요청서 초안을 만들어줘. 빠진 정보는 물어봐.”
- “이 PDF와 영수증 사진으로 의료비 지원을 신청해줘. 상급 결재자와 빠진 정보는 나에게 확인해줘.”
- “사내에서 10월 23일 오후 반차를 신청해줘. 사유는 개인 사정이야.”
- “0.75일 연차를 신청하려고 해. 0.25일과 0.5일의 시간대부터 확인해줘.”
- “이번 달 먼저간DAY 사용 여부와 이번 금요일 사용 가능 여부를 확인해줘.”
- “지난달 신청한 다음 달 연차의 결재상태를 찾아줘.”

## 실행 조건과 규칙

실제 작업에는 데스크톱의 브라우저 제어 기능과 본인 ERP 또는 그룹웨어 로그인이 필요합니다. 브라우저 작업이 필요할 때 Aside의 설치·연결 상태를 확인해 사용 가능한 Aside를 우선하고, 미설치·비실행·연결 불가면 Chrome의 기존 업무 탭을 사용합니다. 사용자가 특정 브라우저·탭을 지정하면 그 선택을 따릅니다. 로그인 화면이나 세션 만료가 확인되면 사용자에게 직접 로그인해 달라고 요청합니다. 이 플러그인은 브라우저 제어 기능 자체를 설치하지 않습니다.

- 초안·검토 요청과 실제 저장·신청·상신·취소 요청을 구분합니다. 이미 받은 정보와 승인 범위는 재사용합니다.
- 0.75일은 **0.25일 한 건 → 0.5일 한 건** 순서로 처리하고 건별 접수를 확인합니다.
- 먼저간DAY는 **사용월 기준 월 1회, 금요일만 가능, 같은 날 다른 연차와 중복 불가**입니다.
- 내역 조회는 **신청일=제출일**을 기준으로 조건을 정하고 **조회/F2**를 실행합니다.
- 야간 시프트의 시간 안내 불일치와 야간근무의 미확인 적용 기준은 개별 신청 전에 확인합니다.
- 구매요청은 부가정보 비고 네 항목과 금액·첨부 기준을 유지하며 저장과 상신을 실제 상태로 확인합니다.
- 의료비는 이번 건의 상급 결재자를 반드시 사용자에게 확인합니다. HR 전용 지원금 칸은 비워 두고, 병원·약국 영수증은 각각 묶어 첨부합니다. 비급여는 지원 대상에서 제외하며 실제 접수·승인·지급을 구분합니다.

## 패키지와 배포

저장소 루트의 `plugin.json`과 `skills/` 아래 28개 스킬 및 참조 자료를 제공합니다. `.agents/plugins/marketplace.json`은 `hct-team` 마켓플레이스에서 이 플러그인을 찾게 합니다. Agent Plugins 1.0 형식이며 데스크톱 실행 조건을 선언했습니다. 별도 MCP 서버, 서비스 계정, API 키를 추가하지 않습니다.

이 저장소는 임직원이 각자 설치해 사용하는 사내 업무 전용 배포 원본입니다. GitHub 업로드가 각 팀원의 PC에 자동으로 설치하는 것은 아닙니다. 개별 스킬을 이미 사용하고 있다면 플러그인 전환 후 같은 업무 스킬의 중복 설치 여부를 확인하세요.

사내 안내문을 포함하므로 기존 자료의 사내 공유 범위에서 사용합니다. 등록·설치 방식은 [OpenAI 플러그인 패키지 안내](https://developers.openai.com/plugins/build/plugins)를, 실행 조건은 [데스크톱 전용 플러그인 안내](https://developers.openai.com/plugins/deploy/desktop-only)를 참조하세요.

문서와 표시명은 사내 업무용 표현으로 정리했으며, 기존 호출명·접속 주소·실제 ERP 메뉴명·원본 안내문은 유지합니다.
